# 開票曲線

專案的檔案總大小與實際磁碟占用在操作過程及交付時均不得超過 **1 GB（1,000,000,000 bytes）**，完整規則見 [專案容量鐵律](AGENTS.md)。

使用支援 `DecompressionStream` 的現代瀏覽器開啟 `index.html` 即可離線使用。內嵌資料與圖表程式採無損 gzip 儲存，載入時在瀏覽器解壓。請完整保留 `assets/frames/`，截圖、放大檢視與選點同步均使用其中的圖片。影片連結需網路。

本頁提供 2012、2016、2020、2024 年總統選舉，以及 2014、2018、2022 年六都縣市首長選舉。以資料來源為列、縣市為欄的矩陣可直接切換交叉格；總統選舉使用「全國」欄，未收錄的組合以「—」表示。

得票數趨勢圖的 X 軸固定使用實際時間，所有年份、縣市、來源及 PNG 匯出預設及重設視圖均顯示選舉當日 **16:00–22:00**，軸名為「觀測時間」；拖曳可在此範圍內以矩形框縮放，PNG 匯出使用完整時段。範圍外的觀測與截圖仍保留，不延長票數圖的時間軸。優先使用畫面時計及已核對的校時依據；仍無法核時、但已取得該影片YouTube直播起始欄位者，可用直播起點加原始影片位置估算，並於頁面、選點時間及PNG匯出標示「時間未核對」。此估算未確認存檔起點、剪輯或延遲，誤差範圍未知；原始時計欄位不以估算值補寫。其餘缺少時間依據的觀測不畫入上方曲線，票數與截圖仍保留。各來源涵蓋時段與可讀票組不同，無法辨識的欄位保留缺值，截圖讀值不等同官方真值。只有固定候選人組的票數完整時，才計算下方開票進度、當選人得票率與走勢誤差。

同片多次語音報時經交叉核對後，可在報時夾住的區段提供分鐘級時間估計；頁面及匯出以「約」和估時說明標示。這類時間不是畫面時計或秒級校準，實際誤差仍可能超過1分鐘；區段外若採直播起點換算，另標示「時間未核對」，不沿用語音校時的精度。

來源矩陣以「電視臺(計票單位)」標示已確認採用單一外部票源者；混用或尚未確認者不加註。候選人線條依該屆登記參選政黨著色，無黨籍使用灰色；圖例依目前來源在顯示時段內最後可讀票數由高至低排列。每位候選人的已知觀測直接連線，不以底色或虛線標註缺讀與跳段；連線只作視覺引導，不新增缺值或改寫票數。下方得票率圖的最終得票率以實線表示。走勢誤差仍只在相同影片、計票來源與時計區段內積分，不跨段計算。

截圖維持原解析度，使用 WebP、AVIF 或保留原始圖片格式；各圖片的格式、壓縮品質與尺寸記錄於 `frontend-assets.json`。壓縮版本須通過票數、候選人身分及時間依據比對；未通過時採用較高品質版本或保留原圖。清單另記錄原圖與交付圖片各自的 SHA-256，原圖 hash 作來源識別；其餘原始研究檔案未隨此前端包保留。

此資料夾為可直接使用的靜態前端，不含研究管線或測試環境。Git 保存前端程式與圖片雜湊清單；截圖保留在 `assets/frames/`，不納入版本控制。
