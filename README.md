# 開票曲線

專案的檔案總大小與實際磁碟占用在操作過程及交付時均不得超過 **1 GB（1,000,000,000 bytes）**，完整規則見 [專案容量鐵律](AGENTS.md)。

開啟 `index.html` 即可離線使用。請完整保留 `assets/frames/`，截圖、放大檢視與選點同步均使用其中的 WebP 圖片。影片連結需網路。

本頁提供 2004 至 2024 年六屆總統選舉，以及 2022、2018、2014、2010、2006 年縣市首長選舉入口。2004 年總統選舉目前沒有可用觀測；2010 五都與 2006 臺北、高雄（合併前）仍缺符合條件的長片觀測。

得票數趨勢圖的 X 軸固定使用可確認的實際時間。缺少實際時間的觀測不畫入上方曲線，票數與截圖仍保留；影片位置只用於定位原始畫面。各來源涵蓋時段與可讀票組不同，無法辨識的欄位保留缺值，截圖讀值不等同官方真值。只有固定候選人組的票數完整時，才計算下方開票進度、當選人得票率與走勢誤差。

截圖以 WebP 壓縮、維持原解析度；`frontend-assets.json` 記錄壓縮品質、圖片尺寸、原圖與衍生圖片各自的 SHA-256。清單預設品質為 90，新增歷史選舉圖片以各項目的品質 85 覆寫。原圖 hash 僅作來源識別，原始研究檔案未隨此前端包保留。

此資料夾為可直接使用的靜態前端，不含研究管線或測試環境。Git 保存前端程式與圖片雜湊清單；截圖保留在 `assets/frames/`，不納入版本控制。
