資料來源與研究限制

本站整理歷屆選舉的公開開票資料與影音畫面，供研究及查核使用，並非即時開票服務或選舉預測。

畫面票數可能包含原始播出錯誤、辨識誤差及時間估計；最終選舉結果以中央選舉委員會公告為準。缺漏與無法確認的資料依頁面標示保留。

各來源的收錄場次、時段與資料完整度不同。走勢偏差及領先穩定時間僅反映已收錄資料，不能直接推論媒體的整體準確率、公正性或未來表現。

影音截圖及品牌標誌的相關權利歸原權利人，本站用於來源識別及研究說明。

如發現錯誤，請透過 GitHub Issues 提供選舉年份、選區、資料來源、疑似錯誤及可公開查閱的佐證，供查核與更正。回報內容會公開，請勿附上個人敏感資訊。
